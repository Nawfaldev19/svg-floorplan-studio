# Support

Floorplan Studio is a demo project; support is best effort, with no guaranteed response time.

- **Questions, ideas and bugs:** open an issue with the [issue forms](../../issues/new/choose). For a bug, include the browser, the steps and, if possible, an exported plan.
- **Accessibility barriers:** see [ACCESSIBILITY.md](ACCESSIBILITY.md).
- **Security problems:** report privately as described in [SECURITY.md](SECURITY.md).

The [documentation map](docs/README.md) and the [feature catalogue](docs/reference/features.md) may already have the answer. Supported: the latest release in current Chromium-based browsers, Firefox and Safari; only Chromium is tested automatically. Servers, accounts, collaboration and hosting help are out of [scope](docs/explanation/scope.md).
