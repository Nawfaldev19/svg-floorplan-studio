# Code of conduct

This short code of conduct is inspired by the Contributor Covenant. It applies wherever people work on Floorplan Studio together: issues, pull requests and discussions.

## Expected

- Be kind and patient, and assume good intent.
- Give and accept feedback about the work, not the person.
- Use welcoming, inclusive language; people differ in background, ability and experience.
- Credit other people's work.

## Not acceptable

- Harassment, insults, threats or personal attacks.
- Discriminatory jokes or language, sexualised language or imagery.
- Publishing someone's private information without permission.
- Repeatedly derailing discussions or ignoring a request to stop.

## Enforcement

The maintainer may edit or remove contributions and block anyone who does not follow this code. Report a problem privately through the contact details on the maintainer's GitHub profile, or, if nothing else is available, through the repository's [private vulnerability reporting](../../security/advisories/new) form. Reports are handled confidentially, and the response is proportionate: a note, a warning, or a temporary or permanent block.
