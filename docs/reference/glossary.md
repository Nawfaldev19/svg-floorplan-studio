# Glossary

Terms used in the code, the UI and these documents.

| Term                      | Meaning                                                                                                                                                                     | In code                                                                |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Plan                      | One floor: title, grid size, items and groups. What export writes and autosave stores.                                                                                      | `PlanDocument`                                                         |
| Item                      | A desk, meeting room, lounge, planter or wall on the floor.                                                                                                                 | `PlanItem`                                                             |
| Kind                      | An item's type; sets its shape, default and minimum size, and add shortcut.                                                                                                 | `ItemKind`, `KIND_SPECS`                                               |
| Amenity, tag              | What an item offers: standing desk, dual monitor, quiet area, by a window, step-free access.                                                                                | `AmenityTag`, `AMENITY_SPECS`                                          |
| Glyph                     | The shape marking an amenity on the plan (triangle, square, circle, diamond, plus), drawn in its colour.                                                                    | `AmenityMark`                                                          |
| Group                     | Two or more named items that select and move together; no transform of its own.                                                                                             | `PlanGroup`, `groupId`                                                 |
| Pod, bench                | Demo-plan groups: a pod is four desks ("Fern pod"), a bench a line of desks ("Quiet bench").                                                                                | `createDemoPlan`                                                       |
| Selection, marquee        | The items an edit acts on; the marquee is a box dragged on empty canvas that selects every item fully inside it.                                                            | `EditorState.selection`, `itemsInsideBox`                              |
| Handle                    | One of eight squares on a selected item that resize it; the knob above it rotates.                                                                                          | `HANDLES`, `SelectionOverlay`                                          |
| Snap, grid                | Rounding positions and sizes to the plan's grid step (10 cm by default).                                                                                                    | `snapTo`, `gridSize`                                                   |
| Nudge                     | Moving the selection one grid step (five with Shift) with an arrow key.                                                                                                     | `nudge` action                                                         |
| Coalesce (history)        | Merging nudges of the same selection less than `COALESCE_WINDOW_MS` apart into one undo step.                                                                               | `Change.coalesce`, `record`                                            |
| Tag brush                 | The mode in which a click or drag adds or removes the active amenity on the items it touches.                                                                               | `EditorMode` `'tag'`, `paintTag`                                       |
| Outline                   | The listbox of every item beside the canvas.                                                                                                                                | `OutlinePanel`                                                         |
| Inspector                 | The panel editing the selected item's name, geometry and amenities, or the plan title.                                                                                      | `Inspector`                                                            |
| Drawer, sheet             | The outline or inspector over the canvas: a side drawer on tablets, a bottom sheet on phones. Not modal.                                                                    | `DrawerPane`, `data-drawer`                                            |
| Layout                    | The editor arrangement for the window width: phone, tablet, desktop or wide.                                                                                                | `EditorLayout`, `useEditorLayout`, `data-layout`                       |
| Overflow menu             | "More tools": the menu holding tools that do not fit on the toolbar at the current width.                                                                                   | `MenuButton` in `Toolbar`                                              |
| Viewer                    | The read-only view for members, and the component behind it.                                                                                                                | `ViewerPage`, `PlanViewer`                                             |
| Highlight                 | In the viewer, the amenity whose items stay at full strength while the rest dim.                                                                                            | `highlight` prop                                                       |
| Reading order             | Keyboard order of items: 40 cm lines from top to bottom, each read left to right.                                                                                           | `readingOrder`                                                         |
| Preset                    | A built-in plan: demo, blank, or the deterministic 3,000-desk stress floor for seeing culling at work.                                                                      | `createDemoPlan`, `createBlankPlan`, `createStressPlan`                |
| Coordinates               | World: centimetres on the floor, y pointing down. Screen: CSS pixels relative to the canvas. Item-local: origin at an item's centre, axes along the item.                   | `Point`, `Box`, `screenToWorld`, `worldToScreen`, `toLocal`, `toWorld` |
| Viewport, camera          | The current zoom and pan, `screen = world × scale + offset`; not part of the document or history.                                                                           | `Viewport`                                                             |
| Culling                   | Drawing only items whose rotated bounds meet the visible area.                                                                                                              | `visibleItems`                                                         |
| Operation, change         | An operation is one invertible step (insert, remove, patch, groups, title, replace); a change is one undo step, a labelled list of operations with the selection around it. | `Operation`, `Change`                                                  |
| Gesture                   | A pointer interaction from press to release: move, resize, rotate, marquee, paint, pan, pinch.                                                                              | `useCanvasGestures`                                                    |
| Preview                   | Temporary item positions shown during a gesture, before it commits.                                                                                                         | `preview`                                                              |
| Live region               | Visually hidden status text that screen readers announce after each action.                                                                                                 | `announcement`                                                         |
| Schema version, migration | The file-format version in every plan file; this build writes 2, reads 1 and 2, and upgrades 1 to 2.                                                                        | `CURRENT_SCHEMA_VERSION`, `migrateV1`                                  |
| Larkspur                  | The fictional co-working space, and the name of the design tokens.                                                                                                          | `tokens.css`, `createDemoPlan`                                         |
