# OWASP ASVS 5.0.0 mapping

A chapter-level self-assessment of this client-only app against the [OWASP Application Security Verification Standard 5.0.0](https://owasp.org/www-project-application-security-verification-standard/); not an audit or certification. Threats and residual risks are in the [threat model](threat-model.md).
